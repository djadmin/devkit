Step 1 — Install
1
CLI + menu bar app
Run this in Terminal. Requires macOS 14+ and Homebrew.
brew tap djadmin/tap
brew install devkit
brew install --cask devkit
devkit bootstrap
2
Register an app to try it
If you have something running on localhost, bring it in.
devkit register myapp --port 3000 --managed-by external
3
Wire your AI agent (optional but the point)
Add this to ~/.claude/CLAUDE.md so Claude registers apps automatically.
## devkit — App Registration
After creating any web app or local service:
devkit register <name> --port <port> --cmd "<start-cmd>"
What to focus on
🔌
Install & bootstrap
Does Caddy start? Does devkit bootstrap finish cleanly?
📋
Register + start/stop
Do lifecycle commands work? Does devkit stop actually kill the process?
🖥️
Menu bar app
Does the popover open? Does status poll correctly? Does the Mac window open?
🤖
Agent auto-register
Ask Claude to build something. Does it auto-register? Does the app appear?
Known rough edges
Externally-supervised processes (nodemon, launchd, respawners) may restart after stop — a race, not a bug we've fixed yet
The Mac window (Services / Agent Setup / Discover / Logs) is new in v0.3.0 — most likely to have visual issues on different display sizes
Auto-update not implemented — you'll need to re-brew install for new versions
Launch at login not yet available
