How it works

Three steps. Then automatic.

Set it up once and every AI-built project takes care of itself.

1
Install devkit
Install the CLI and the macOS menu bar app.
brew install devkit # menu bar app: see GitHub
2
Add one line to your agent
Tell your AI agent to register every new app it builds.
# In ~/.claude/CLAUDE.md: After creating any web app, run: devkit register <name> --port <port>
3
Build. It just appears.
Every new project auto-registers. Opens in one click.
nova.localhost 🟢 running forge.localhost 🟢 running orbit.localhost 🔴 stopped
